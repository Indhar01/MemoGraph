This is a starter vault generated by `memograph quickstart`. It contains a small, interconnected knowledge base about Python development — the kind of notes a working developer might keep — so you can immediately see what MemoGraph does instead of starting from an empty directory.

Things to try:

- `memograph search "should I use async or threads"` — should surface [[concurrency-decision]] and [[python-async]] together because they're linked.
- `memograph search "lockfile" --depth 2` — finds [[poetry-vs-uv]] directly, then walks one hop to [[python-dev-tooling]] via the wikilink.
- Open `memograph/data/sample_vault/concurrency-decision.md` in any editor and notice the `[[wikilinks]]`. Those are the graph edges.
- Run `memograph stats` to see the graph: 15 memories, ~25 wikilinks, 4 memory types, salience scores ranging from 0.6 to 1.0.

When you're ready to start your own vault, just point MemoGraph at a different directory: `memograph --vault ~/notes ingest`. Markdown files with `[[wikilinks]]` and YAML frontmatter are all you need; everything else MemoGraph indexes is derived.

Delete this vault any time — it's just markdown files. Re-create it with `memograph quickstart` whenever you want a fresh demo.
